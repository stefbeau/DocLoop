# Exporting data

You can export the data behind any chart.

## Export a chart

1. Open the chart.
2. Select **Export**.
3. Choose **CSV (legacy)** or **CSV** from the Export menu.

The legacy CSV format keeps the column order used before version 4.

See [Supported file formats](file-formats.md).
